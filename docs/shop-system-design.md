## 二、熔炼

- 玩家可以熔炼**背包中任意一张**卡牌（包括唯一持有的最后一张）
- 熔炼：`Count - 1`，如果 Count 减到 0 则删除 `UserWeaponLink` / `UserSkillLink` 记录
- 武器与技能均可熔炼（它们都是卡牌）
- 熔炼后，若该卡牌为 `IsUnique = true`，玩家不再持有，则该卡重新进入抽取池
- 系统保留 **Fist（拳头）** 作为兜底攻击，玩家即使熔炼所有卡牌也能正常战斗

## 三、稀有度说明

| 稀有度 | 代号 | IsUnique | 获取渠道 |
|--------|------|---------|---------|
| R1 普通 | Common | false | 战斗奖励、所有商店 |
| R2 稀有 | Rare | false | 战斗奖励、所有商店 |
| R3 史诗 | Epic | false | 战斗奖励（低概率）、所有商店 |
| R4 传奇 | Legend | **true（全部）** | **仅限商店/抽卡**，不进战斗/升级奖励池 |

> R4 全部为 `IsUnique`：集齐所有 R4 后，相关抽取入口自动禁用。  
> R1–R3 均有非 Unique 卡，理论上不会出现池耗尽。

## 四、每日轮换商店

### 刷新机制

- **系统刷新**：以服务端时间为准，每 3 小时整刷新（0:00 / 3:00 / 6:00 … 21:00）
- **手动刷新**：消耗 **20 LotteryPoint**，不重置系统倒计时  
  例：0:00 系统刷新，2:00 手动刷新，3:00 系统仍然自动刷新
- 刷新范围：**重新生成所有非锁定槽位**（含已购买的槽位）

### 槽位规则

- 共 4 个槽位（`SlotIndex` 0–3）
- 每个槽位独立随机：先骰类型（50% 武器 / 50% 技能），再骰稀有度
- **已购买**的槽位在下次刷新前不再显示
- **Unique 卡失效**：玩家从任何渠道（升级、抽卡、购买）获得某张 `IsUnique` 卡时，服务端立即检查并删除商店中对应槽位，同时释放该槽位上的锁

### 锁定功能

- 同时最多锁定 **1 个**槽位
- 锁定的槽位在刷新时保留不变
- 若锁定槽位上的 Unique 卡被玩家从其他渠道获得：槽位**立即消失，锁释放**

### 槽位稀有度权重与价格

| 稀有度 | 出现权重 | 购买价（LotteryPoint）|
|--------|---------|----------------------|
| R1 | 50% | 20 |
| R2 | 30% | 50 |
| R3 | 18% | 120 |
| R4 | **2%** | 400 |

### 持久化（新表 `UserDailyShopSlot`）

```
UserDailyShopSlot
├── Id              int PK
├── UserId          int FK → User
├── SlotIndex       int (0–3)
├── ItemType        string ('WEAPON' | 'SKILL')
├── ItemId          int
├── Price           int  （生成时锁定）
├── IsPurchased     bool
└── IsLocked        bool
```

`User` 表新增字段：
- `LotteryPoint` int
- `LastBattleTime` DateTime?（战斗冷却用）

## 五、职业抽

- **4 个入口**，对应 4 个职业（MORTAL / WARRIOR / RANGER / MAGICIAN）
- 费用：**40 LotteryPoint / 次**
- 稀有度随机，职业固定
- 抽到的卡直接进入背包（无选择步骤）
- 只匹配**主职业**（`Profession` 字段），不看 `SecondProfession`

### 稀有度权重

| 稀有度 | 权重 |
|--------|------|
| R1 | 55% |
| R2 | 30% |
| R3 | 12% |
| R4 | 3% |

### R4 池耗尽处理

若抽到 R4 但该职业下已无可用 R4（全为 Unique 且已拥有）：  
→ **重新骰稀有度**，直到命中有货的组合（R1–R3 始终有货）

## 六、稀有度抽

- **4 个入口**，对应 4 个稀有度
- 职业随机（从该稀有度下所有可用卡中随机），类型随机（武器/技能各 50%）
- 抽到的卡直接进入背包（无选择步骤）

### 费用

| 稀有度 | 费用（LotteryPoint）|
|--------|---------------------|
| R1 | 20 |
| R2 | 50 |
| R3 | 120 |
| R4 | 400 |

### R4 池耗尽处理

当玩家集齐所有 R4 Unique 卡时：  
→ **R4 按钮直接禁用**，前端展示"已集齐"状态

## 七、抽卡池通用规则

所有抽取渠道（商店槽位生成、职业抽、稀有度抽）共用同一套池过滤逻辑：

```
可用卡 = 所有卡牌
  过滤：IsUnique == false  → 始终可用（允许重复）
  过滤：IsUnique == true   → 仅当玩家尚未持有 AND 不在待领奖励队列中
```

> 复用现有 `GetLockedWeapons` / `GetLockedSkills` 逻辑（DataHelper 已实现）
